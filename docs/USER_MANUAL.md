# MLMS User Manual

Start the program, choose **1. Log in**, and type your username and password. You will see the menu for
your role. Type the number of an option and press Enter. If you make a mistake the program shows a
message starting with `[!]` and takes you back to the menu - nothing is saved.

Dates are typed as `YYYY-MM-DD HH:MM`, for example `2026-11-20 16:00`.
Five wrong passwords in a row lock your account for 15 minutes.

---

## Student
| Option | What it does |
|---|---|
| 1. My assignments | Lists your assignments, the deadline that applies to **you** (including any extension) and whether you have submitted. |
| 2. Submit or resubmit work | Choose the assignment ID and type your answer or the path of your file. |
| 3. My released marks and feedback | Shows marks the HoD has released, any late penalty, and the lecturer's feedback. |
| 4. Change my password | |

Good to know:
- You can resubmit as many times as you like **before** the deadline. Your latest version is the one marked.
- After the deadline you can still submit once, but it is marked late: 10% of the total mark is taken off
  for each started day late, for up to 3 days. After 3 days the work is recorded but the mark is 0.
- Marks only appear after the Head of Department has checked and released them.

## Lecturer
| Option | What it does |
|---|---|
| 1. My courses | Courses you are assigned to. |
| 2. Create assignment | Title, description, deadline (must be in the future) and maximum mark. |
| 3. List my assignments | Shows assignment IDs. |
| 4. View submissions | All submissions for one assignment: student, status, versions, days late, your mark. |
| 5. Mark a submission | Only after that student's deadline has passed. Enter the raw mark and written feedback - the late penalty is worked out for you. |
| 6. Correct a mark | Change a mark that is still waiting for the HoD or was returned by the HoD. A reason is required. |
| 7. Grant an individual extension | Give one student a later deadline with a reason. Not possible once the work is marked. |
| 8. Change my password | |

Your marks go to the HoD for moderation; students cannot see them until they are released.

## Head of Department
| Option | What it does |
|---|---|
| 1. Marks awaiting moderation | Every mark in your department waiting for you, with penalty, extension and feedback. |
| 2. Approve a mark | Accept the mark as it is. |
| 3. Amend a mark | Enter a new raw mark and a reason. The late penalty is recalculated. The mark is then approved. |
| 4. Return a mark | Send it back to the lecturer with a reason. |
| 5. Release marks | Releases all approved marks for one assignment. Refused if anything is unmarked or not yet approved. |
| 6. Department audit log | Every mark change in your department: who, when, old value, new value, reason. |
| 7. Change my password | |

## Administrator
| Option | What it does |
|---|---|
| 1. Create user account | Choose the role. HoDs need a department; students need a student number. |
| 2. List users | |
| 3. Activate / deactivate | A deactivated user cannot log in. Activating also clears a lock. |
| 4. Edit user details | Name and department. |
| 5. Reset a password | Also unlocks the account. |
| 6-9. Departments and courses | Create and list. |
| 10. Assign lecturer | Link a lecturer to a course. |
| 11. Enrol student | Link a student to a course. |
| 12. Audit log | Whole-system audit log, with optional filters by assignment or student. |
| 13. Change my password | |

The administrator manages accounts and courses but cannot see or change marks.
